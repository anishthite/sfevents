Algorithm

  1. Cron invokes the private connector for discoverable, RSVP, saved, and followed events.
  2. Normalize each source event into events; upsert by source + source_id.
  3. Record the result in sync_runs; leave the prior snapshot on failure.

Decisions

IDChoice · Rationale
D-001Use a Worker secret for Partiful credentials. Keep account access outside source and browser code.
D-002Use a Service Binding between Workers. Keep MCP traffic private.
D-003Require CONNECTOR_TOKEN on the connector. Block direct calls to its public Worker URL.
D-004Use PARTIFUL_REFRESH_TOKEN over a cookie. The upstream API requires a refreshed Firebase Bearer token.
